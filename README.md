Discord Rules & Roles Bot

Учебный проект Discord бота для управления правилами сервера и ролями. Проект разработан для изучения Discord API, Python и Git workflow.

 🎯 Цель проекта

Отработка базового workflow разработки:
- Работа с Discord API и библиотекой discord.py
- Настройка интентов и прав доступа
- Реализация системы команд
- Управление серверными ролями
- Деплой на Replit

 🛠 Технологии

Основной стек:
- Python 3.8+
- Discord.py - библиотека для работы с Discord API
- Replit - облачная среда разработки
- Git + GitHub - система контроля версий

Архитектура:
- Событийно-ориентированная архитектура
- Префиксные команды ($-команды)
- Настройка через Intents
- Локальное хранение конфигурации

 📋 Функциональность

✅ Базовые команды:
- `$hello` - проверка работоспособности
- `$rule` - отображение правил сервера
- `$roles` - список доступных ролей

✅ Управление ролями:
- `$role <название>` - анализ доступов роли
- Автоматическое определение каналов
- Проверка разрешений

✅ Конфигурация:
- Легкая настройка через код
- Модификация правил и ролей
- Настройка префикса команд

🚀 Быстрый старт

1. Установка
```bash
# Клонирование репозитория
git clone <repository-url>
cd discord-bot

# Установка зависимостей
pip install discord.py
```

2. Настройка бота
1. Создайте приложение на [Discord Developer Portal](https://discord.com/developers/applications)
2. Скопируйте токен бота
3. Отредактируйте `main.py`, заменив токен:
```python
client.run('ВАШ_ТОКЕН')
```

3. Настройка прав
1. В Discord Developer Portal включите:
   - PRESENCE INTENT
   - SERVER MEMBERS INTENT
   - MESSAGE CONTENT INTENT
2. Пригласите бота на сервер с правами администратора

4. Запуск
```bash
python main.py
```

 🔄 Workflow разработки

Таск-трекинг:
- Используется GitHub Issues для управления задачами
- Для каждой задачи создается Issue + ветка в git
- Задачи разбиваются на подзадачи внутри Issue
- При сдаче создается Pull Request в main

Пример Issue:
- Issue: "Реализация команды $role"
- Ветка: `feature/role-analysis`
- Подзадачи: анализ разрешений, форматирование вывода

 🏗 Архитектура

Event-Driven:
- Асинхронная обработка событий
- Декораторы для обработки событий
- Отдельные обработчики для каждого типа

Структура кода:
- Основной клиент Discord
- Обработчики событий `on_ready` и `on_message`
- Система команд с префиксом `$`

 🐛 Отладка

 Распространенные ошибки
- **Missing Intents:** Проверьте настройки в Discord Developer Portal
- **Токен недействителен:** Обновите токен в коде
- **Нет прав доступа:** Проверьте права бота на сервере
