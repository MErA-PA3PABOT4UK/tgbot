Discord Bot Project

Проект Discord бота для управления правилами и ролями на сервере.
📁 Структура проекта

```
├── .config/                    # Конфигурационные файлы
├── .git/                      # Git репозиторий
├── .local/                    # Локальные настройки
├── .gitignore                # Игнорируемые файлы Git
├── .replit                   # Конфигурация Replit
├── generated-icon.png        # Иконка проекта
├── main.py                   # Основной код бота
├── pyproject.toml           # Конфигурация зависимостей Python
└── uv.lock                  # Lock-файл зависимостей
```

🚀 Быстрый запуск

Локальный запуск

1. Установите зависимости:
```bash
# Если используете uv
uv install

# Или традиционный способ
pip install -r requirements.txt
```

2. Настройте бота:
   - Создайте бота на [Discord Developer Portal](https://discord.com/developers/applications)
   - Скопируйте токен бота
   - Добавьте токен в код или настройте переменные окружения

3. Запустите бота:
```bash
python main.py
```

 Запуск на Replit

Проект полностью готов к запуску на Replit:
1. Импортируйте репозиторий в Replit
2. Настройте Secrets для токена бота
3. Нажмите "Run"

 ⚙️ Конфигурация

 Основные настройки

1. Токен бота:
   - Добавьте токен в `main.py` или используйте переменные окружения
   - Пример для Replit: добавьте в Secrets как `DISCORD_TOKEN`

2. Префикс команд: По умолчанию используется `$`

 Файлы конфигурации

- `.replit` - настройки среды выполнения Replit
- `pyproject.toml` - зависимости и метаданные проекта
- `.gitignore` - игнорируемые файлы для Git

 🛠️ Разработка

 Структура кода

Основной код находится в `main.py` и включает:
- Настройку intents и клиента Discord
- Обработку событий (on_ready, on_message)
- Команды бота с префиксом `$`

 Добавление новых команд

```python
@client.event
async def on_message(message):
    if message.author == client.user:
        return
    
    # Существующие команды...
    
    # Новая команда
    elif message.content == "$new_command":
        await message.channel.send("Новая команда работает!")
```

 🐛 Отладка

 Распространенные проблемы

1. Бот не запускается:
   - Проверьте токен бота
   - Убедитесь, что включены необходимые intents
   - Проверьте права бота на сервере

2. Команды не работают:
   - Проверьте префикс команд (`$`)
   - Убедитесь, что бот имеет права на чтение/отправку сообщений
   - Проверьте настройки intents в Discord Developer Portal

 Логирование

Бот выводит информацию в консоль при запуске и обработке событий.

 🔒 Безопасность

 Важные предупреждения

1. Никогда не коммитьте токен бота в Git!
2. Используйте переменные окружения или Secrets для хранения токена
3. Токен в текущем коде скомпрометирован - замените его на свой

 Защита токена

Для хранения токена используйте:
- Переменные окружения в локальной среде
- Secrets в Replit
- Файлы `.env` (добавленные в `.gitignore`)
